# EF Enroll Frontend

React + Vite frontend for EF Enroll.

## Setup

```bash
npm install
copy .env.example .env
npm run dev
```

Default API URL:

```text
http://localhost:5000
```

Change it in `.env`:

```text
VITE_API_URL=http://localhost:5000
```

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run preview
```
